# Stark Industries Portal

> "Changing the World for a Better Tomorrow" — Anthony Edward Stark

An ultra-premium, interactive corporate web portal for **Stark Industries**, engineered with an authentic Marvel Cinematic Universe (MCU) / Tony Stark aesthetic.

---

## ⚡ Core Features

- **Futuristic Holographic HUD**: Scanlines, dynamic canvas particle network, glow effects, and responsive telemetry ticker.
- **Interactive Arc Reactor Core**: Animated 10-coil fusion reactor with interactive discharge click interactions and power surge diagnostics.
- **Web Audio API Sound Synthesizer**: Authentic sci-fi acoustic feedback on clicks and commands (toggleable in navigation).
- **Live Battery Detection**: Real-time synchronization of the visitor's device battery level with the Stark power telemetry ribbon.
- **The Armor Vault (Schematics)**: Interactive blueprint viewer for **Mark III**, **Mark V**, **Mark XLIV (Hulkbuster)**, **Mark L**, and **Mark LXXXV**, complete with interactive hotspots and real-time durability/mobility bars.
- **J.A.R.V.I.S. Interactive CLI Terminal**: Functional command prompt supporting MCU easter eggs (`help`, `status`, `suits`, `jarvis`, `avengers`, `override`, `iamironman`, `pepper`).
- **Threat Protocol Mode**: Dynamic theme switcher between Stark Clean Cyan and Hulkbuster Red Alert.
- **The September Foundation**: Leadership overview (Tony Stark & Pepper Potts) with student grant application workflow.

---

## 🚀 Running the Project

Open `index.html` in any modern web browser, or run a local web server:

```bash
npx serve .
```

Navigate to `http://localhost:3000`.
